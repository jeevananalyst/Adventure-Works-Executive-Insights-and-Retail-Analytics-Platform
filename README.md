# Power BI - Adventure Works Report

A comprehensive Power BI report built for the Adventure Works dataset, providing analytical dashboards across customers, sales, products, and regional data.

## Features

* **Interactive Dashboards**: Dynamic views for Customer insights, Product performance, and Sales geographical mapping.
* **Custom Data Model & Visuals**: Pre-configured JSON data models, visual specs, mobile view layouts, and custom theme definitions.
* **Rich Asset Library**: Icons and logos included for visual enhancements (`Customer_Icon`, `Dashboard_Icon`, `Filter_Icon`, `Map_Icon`, `Product_Icon`).
* **Bookmarks & Interactivity**: Configured bookmark actions (`definition/bookmarks/`) for navigation.
